# Security policy

## Report a vulnerability

Email [contact@gladeapi.com](mailto:contact@gladeapi.com) with the subject
`SECURITY: glade-api-examples`. Do not disclose security reports in public
issues.

## Scope

This repository contains public documentation and client examples. Report an
example that exposes credentials, disables TLS verification, sends secrets in
URLs, retries authentication failures indefinitely, or mishandles untrusted
marketplace content.

For a vulnerability in the hosted Glade API service, use the same private
contact address and include the affected endpoint, reproduction steps, and
impact. Never include a working API key in a report; redact it before sending.
